# Contributing to DNVA

Thank you for your interest in the DNVA project.

---

## Project Status

DNVA (DogNutritionVideoAuto) is currently in an early MVP stage.
The project is primarily developed and executed by an AI engineering agent
(Codex Cloud) under strict, document-driven constraints.

At this stage, DNVA is **not a general open-source collaboration project**.

---

## How Contributions Are Handled

- The primary implementation work is performed by Codex Cloud.
- All development tasks, PR boundaries, and acceptance criteria are defined in:

      docs/05_codex_pr_tasks.md

- Human involvement focuses on:
  - Reviewing AI-generated Pull Requests
  - Approving or rejecting changes
  - Providing high-level product and content decisions

---

## Pull Requests

Please do **not** submit unsolicited Pull Requests.

If you believe you can contribute meaningfully, open an Issue first
to discuss the scope and intent before any code changes are made.

---

## Future Updates

This CONTRIBUTING guide may be expanded in future phases
when DNVA opens selected modules for broader collaboration.
